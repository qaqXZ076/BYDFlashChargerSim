# 比亚迪闪充（兆瓦闪充2.0）模拟工具

一个用于模拟多车排队场景下，单个充电桩搭配储能电池组是否能够支撑大客流闪充的交互式 Web 工具。通过实时图表和电池状态，直观展示储能系统的充放电行为。

## 核心功能

- **储能电池组模拟**：8 块独立电池单元，每块实时显示 SOC 及充放状态（⬆️充电 / ⬇️放电 / ⏸️空闲）。
- **两车位并行充电**：支持 1~2 辆车同时充电，每辆车均遵循 1000kW 闪充曲线（SOC 从 10% 到 97%）。
- **电网‑储能‑汽车能量隔离**：电网功率全部用于给储能电池充电，汽车充电所需能量完全由储能电池放电提供。
- **可调节权重**：四种车辆电池容量（53.1 / 85.4 / 23.9 / 122.5 kWh）的出现概率可通过滑块独立调节。
- **放电均衡/非均衡模式**：
  - **均衡放电**：多个电池按 SOC 从高到低同时放电。
  - **非均衡放电**：始终只使用一块 SOC 最高的电池放电，直至放空才切换下一块。
- **电网单块充电**：无论何种模式，电网始终只给一块 SOC 最低且未放电的电池充电，充满后切换下一块。
- **自动暂停条件**：当两辆车同时处于充电状态，且没有任何一块电池（SOC>0%）可供放电时（即所有可用电池均已被耗尽），模拟自动暂停，提示已达极限。
- **实时能量流向图**：
  - 左轴 SOC：蓝色/紫色曲线分别代表两辆车的 SOC；绿色虚线代表储能总 SOC。
  - 右轴功率：黄色/橙色柱状图分别代表两把枪的实时功率。
  - 红色加粗虚线：标注当前设定的“电网功率”上限。
- **完整日志保留**：重置前所有历史日志均保存在右侧面板（最多 30 条），方便复盘。

## 使用说明

1. **调整参数**：在顶部配置面板中，可设定电网功率、储能总容量、车位数、换车静置时间、温度模式、模拟速度、车辆容量权重以及放电均衡模式。
2. **开始模拟**：点击 **▶ 开始模拟** 按钮，系统将以设定速度运行，车辆会自动进入并开始充电。按钮变为“暂停模拟”。
3. **观察状态**：
   - 储能电池格中的箭头指示当前充放电方向，SOC 百分比实时更新。
   - 中央图表动态绘制 SOC 曲线和功率柱状图。
   - 右侧功率详情显示各枪功率、电网供给和储能放电。
4. **暂停与重置**：
   - 点击 **暂停模拟** 可随时暂停，再次点击继续。
   - 点击 **重置** 将清空所有数据，恢复到初始状态。
5. **自动暂停条件**：当两车都在充电且无剩余可用放电电池时，模拟自动暂停并提示，方便用户观察“耗尽”瞬间。

## 参数配置详解

| 参数 | 说明 |
|------|------|
| 电网功率 | 电网可提供的最大功率，全部用于给储能电池充电（120/240/360/600 kW）。 |
| 储能总容量 | 8 块电池的总容量（kWh），每块容量 = 总容量 / 8。 |
| 车位数 | 1 或 2，决定同时充电的车辆数。 |
| 换车静置 | 车辆充满后停留的时间（分钟），模拟插拔枪操作。 |
| 温度模式 | 常温或低温（低温下车辆需预热 3 分钟，耗电 10kW）。 |
| 模拟速度 | 1x ~ 120x，控制模拟时间流逝速度。 |
| 车辆电池容量权重 | 四种电池容量的出现概率，滑块数值独立调节，总和不必为 100，程序按权重比例随机选择。 |
| 放电均衡 | 均衡：多电池同时放电；非均衡：单电池连续放电，放空才切换。 |
